A complete C++ console-based application for managing movie ticket bookings in a cinema hall. The system allows administrators to add, view, update, and delete movies, schedule shows with date, time, hall number, and ticket price, and manage seat bookings with a visual seat layout display. Customers can book multiple seats, view available shows, cancel bookings, and all data is automatically saved to text files for persistence. Built with Object-Oriented Programming principles, the system uses three main classes (Movie, Show, and Booking) to handle all operations efficiently with a user-friendly colored interface.

Key Features: Movie Management | Show Scheduling | Seat Booking | Cancel Bookings | View Bookings | Auto-Save to Files
